# منابع و حدود تأیید محتوا

بررسی این پروژه: ۲۰۲۶-۱۱-۰۱. مخزن جدید هنگام شروع بدون فایل و commit بود. منابع خوانده‌شده از checkout فقط‌خواندنی مخزن `mo90mosleh/SanaDeviceLanding` در `/tmp/SanaDeviceLanding` انتخاب شدند. هیچ فایل اتصال فرم، webhook، کلید، اطلاعات مشتری، تنظیم محیط یا انتشار آن پروژه منتقل نشد. مخزن قبلی تغییر نکرده است.

## لوگو و تصاویر

فایل اصلی لوگوی موجود چندرنگ است و برخلاف توصیف درخواست، حرف S آن آبی و قرمز آن در حرف A است. برای جلوگیری از ساختن رنگ جدید، قرمز خود فایل (`#bf0015`، نمونه غالب از ناحیه قرمز) مبنا قرار گرفت. نسخه تک‌رنگ با CSS mask از آلفای دقیق همان لوگو ساخته می‌شود؛ شکل و نسبت حروف حفظ شده و PNG اصلی جدا و دست‌نخورده باقی است. این رنگ مبنای سایت هم هست. برای نسخه عملیاتی، کد رنگ رسمی سانا باید تأیید شود.

تصاویر دستگاه‌ها واقعی و منتقل‌شده‌اند. viewport SVG برای حذف فضای خالی اضافی اطراف BHA3000/BHA5000 از روش مستند مخزن قبلی استفاده می‌کند و بخش‌های دستگاه را نمی‌سازد. تصویر بسته کیت موجود نبود؛ آیکون نمادین در کارت‌ها با عبارت «تصویر نمادین بسته؛ عکس محصول نیست» نمایش داده می‌شود.

## دستگاه‌ها و اختلاف BHA5000

- FS-114: Finecare FIA Meter II Plus SE، REF W911، صفحه ۲ PDF همان مدل.
- FS-205: Finecare FIA Meter III Plus، REF W914، صفحه ۲ PDF همان مدل.
- BHA3000، BHA5000 و BHA5100: مشخصات از PDF اختصاصی همان مدل. داده نسخه‌ها ترکیب نشده است.
- BHA5000: مشخصات این دمو طبق کاتالوگ ۱۰٫۴ اینچ / ۱۰٬۰۰۰ نتیجه است؛ گزارش مخزن قبلی اختلاف با نسخه وب‌سایت سازنده (۱۰٫۱ اینچ / ۱۰۰٬۰۰۰) را ثبت کرده است. پیکربندی دستگاه عرضه‌شونده باید تأیید شود. تصویر فعلی از منبع سازنده طبق گزارش قبلی است؛ تصویر دارای برچسب دامپزشکی کاتالوگ قدیمی به کارت عمومی منتقل نشده است.

## کیت‌ها و مصرفی‌ها

صفحه ۱ هر دو PDF Finecare به‌صورت تصویر رندر و بررسی شد. نام و کد کاتالوگی ۴۹ آزمون منتخب از جدول مشترک استخراج شده‌اند؛ ۱۵ قلم برای تجربه سفارش دمو فعال‌اند و بقیه فقط معرفی سازنده‌اند. همه مدل‌های نسبت‌داده‌شده صرفاً در منوی کاتالوگ همان مدل آمده‌اند؛ تطبیق دقیق SKU، نسخه دستگاه و IFU نهایی انجام نشده است. `verified` در مدل فعلی یعنی «مجاز برای سفارش آزمایشی»، نه تأیید علمی یا مجوز عرضه. رابط این محدودیت را صریح نشان می‌دهد.

تعداد تست هر بسته `null` است و «نیازمند تأیید» نمایش داده می‌شود. هیچ حجم بسته، نگهداری، مجوز یا ادعای تشخیصی از روی حدس اضافه نشده است. کدهای کاتالوگی به معنی SKU قابل تأمین نیستند؛ کدهای جایگزین، نسخه‌های One Step، ترکیبی و نسخه‌های نمونه متفاوت یکسان فرض نشده‌اند. فهرست نمونه، همه منوی تجاری Wondfo یا عرضه سانا نیست.

صفحه ۴ کاتالوگ BHA3000 دسته معرف‌های Diluent و Lyse را ذکر می‌کند. این دو صرفاً دسته مصرفی هستند؛ برند سازنده محلول «نیازمند تأیید» ثبت شده؛ این اقلام به معنای تأیید محلول داخلی یا SKU نیستند. مدل سازگار برای این اقلام خالی است، موجودی صفر و دکمه سفارش غیرفعال است. هیچ محلول داخلی با سازگاری قطعی معرفی نشده است. کد، بسته‌بندی و سازگاری واقعی CBC همچنان نیازمند مدرک و تأیید ساناست.

## قیمت و دسترسی اینترنت

قیمت‌های عمومی همسان از نظر کد و اندازه بسته در دسترس تأییدشده قرار نگرفتند. دسترسی HTTPS مستقیم به `cbc.ortanes.com` و صفحه رسمی Getein در این محیط با خطای CONNECT 403 محدودیت شبکه پاسخ گرفت؛ هیچ bypass یا کاهش TLS انجام نشد. هیچ قیمت خارجی تبدیل نشده و منبع قیمت واقعی ادعا نشده است. همه قیمت‌ها به تومان، فرضی و صرفاً برای نمایش تفاوت آنلاین و چک سه‌ماهه هستند. بنابراین تاریخ، ارز و اندازه بسته قیمت خارجی وجود ندارد که گزارش شود.

آرشیوهای FINECARE.rar، IVDR.rar و ZIP نام‌برده در مسیرهای پروژه و مسیرهای قابل‌خواندن محیط پیدا نشدند. دسترسی به دسکتاپ یا فایل‌های گفت‌وگوهای دیگر فرض نشده است. هیچ آرشیو حجیم یا مدرک نامرتبط منتقل نشده است.

## تأیید لازم پیش از نسخه واقعی

سانا باید نام حقوقی و کد رنگ رسمی، تماس و نشانی، پیکربندی BHA5000، SKU و IFU کیت‌ها، سازگاری هر نسخه، تعداد تست بسته، کد و سازنده مصرفی CBC، موجودی و قیمت واقعی، شرایط فروش و چک، خدمات/ضمانت و مجوزها را تأیید کند. جایگاه اینماد صرفاً با متن «محل نمایش نماد اعتماد» است و نماد یا لینک اعتبار ساختگی ندارد.

## منابع اصلاحات بازخورد — ۲۰۲۶-۱۱-۰۲

لوگوی Getein و Wondfo از همان مسیرهای branding مخزن قبلی منتقل شدند. رنگ سبز اصلی ناحیه GP در لوگوی Getein (`#087d28`) و آبی Wondfo برای تفکیک خانواده‌ها استفاده شده است؛ رنگ اصلی سانا همچنان قرمز است.

دو عکس Finecare با `pdfimages` از صفحه ۱ `fs-114-catalog.pdf` استخراج شدند: کاست CRP (`finecare-cassette.png`) و ID chip (`finecare-id-chip.png`). هیچ نوشته یا بسته‌بندی جدیدی روی عکس ساخته نشده است. این تصویر، مرجع خانواده Finecare با برچسب مربوط است و عکس دقیق HbA1c/TSH و دیگر SKUها نیست. برای نسخه تجاری باید عکس همان SKU و بسته‌بندی قابل عرضه تحویل شود.

favicon در `public/favicon.svg` حرف S تصویر اصلی را با mask و فیلتر SVG مستقل نمایش می‌دهد. بخش‌های دیگر لوگو نمایش داده نمی‌شوند؛ رنگ خروجی قرمز است و اصل PNG تغییری نکرده است. نشان تصویری مرکز بقراط در `public/profile/boghrat.svg` یک آواتار برداری ساخته‌شده برای داده ساختگی مرکز است، نه عکس شخص یا آزمایشگاه واقعی.

مرز نقشه ایران از داده public domain مجموعه **Natural Earth 1:110m countries**، ویژگی `ADMIN=Iran` استخراج شده است:
`https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson`
تنها مختصات مرز ایران در `src/iran-outline.ts` نگه داشته شده، نه کل مجموعه جهان. مرز برای نمایش کلی است و دقت خیابان یا کاداستر ندارد. مراکز تقریبی شهرهای `src/locations.ts` برای جابه‌جایی اولیه نمای نقشه‌اند؛ کاربر نشان موقعیت را انتخاب می‌کند و نشانی متنی مستقل ذخیره می‌شود. هیچ سرویس نقشه، tile، geocoding یا کلید بیرونی هنگام اجرا استفاده نمی‌شود.

## اصلاحات بعدی — نشان‌ها، نقشه و تصاویر متمایز

- لوگوی Getein در تمام اجزای سایت از یک renderer مشترک با viewport `0 0 258 59` روی PNG اصلی `400×59` نمایش داده می‌شود؛ ستون Stock code و کد بورس سمت راست و جداکننده آن بیرون از viewport است. فایل اصلی برای منشأ دست‌نخورده باقی است؛ این برش روی PDFهای رسمی سازنده اعمال نشده است.
- favicon فعلی `public/favicon.svg` یک مسیر برداری تک‌رنگ S است؛ bitmap، فیلتر، سایه و مستطیل پس‌زمینه ندارد. query نسخه در link آیکن برای عبور از cache آیکن قدیمی استفاده می‌شود.
- پس از درخواست متفاوت بودن عکس کیت‌ها، کاربر استفاده از تصویر گرافیکی اختصاصی را صریحاً پذیرفت. `KitArtwork` برای هر نام/کد آزمون یک گرافیک برداری متمایز با رنگ و نشان مرتبط می‌سازد. همه کارت‌ها عنوان «تصویر گرافیکی» دارند. این‌ها عکس رسمی یا اثبات شکل بسته‌بندی هر SKU نیستند و مشخصات تأییدنشده‌ای مانند اندازه بسته، نگهداری و مجوز به تصویر اضافه نشده است. عکس مشترک CRP دیگر به‌عنوان تصویر همه محصولات نمایش داده نمی‌شود.
- Leaflet 1.9.4، متن‌باز با مجوز BSD-2-Clause، جای نقشه outline قبلی را گرفته است. متن کامل مجوز در `public/licenses/leaflet.txt` همراه خروجی انتشار نگه داشته می‌شود. منبع کاشی‌ها `https://tile.openstreetmap.org/{z}/{x}/{y}.png` است؛ attribution با پیوند حقوق OpenStreetMap روی نقشه نمایش دارد. هیچ token یا API key لازم نیست و دانلود انبوه/آفلاین کاشی‌ها انجام نمی‌شود. نقشه فقط هنگام باز شدن ویرایش آدرس به صورت lazy بارگیری می‌شود. اطلاعات مرکز و سفارش به سرویس نقشه ارسال نمی‌شوند؛ درخواست‌های عادی کاشی، محدوده نمای نقشه را طبق عملکرد استاندارد نقشه آنلاین مشخص می‌کنند.
- اتصال وب‌سایت Wondfo از داخل محیط در زمان بررسی با CONNECT 403 مسدود بود. پس از پذیرش تصاویر گرافیکی، دریافت تصویر رسمی پیش‌نیاز این اصلاح نیست. برای بررسی اتصال خارجی نقشه، فقط `tile.openstreetmap.org` در پیش‌نویس دسترسی شبکه محیط باقی گذاشته شد. سیاست شبکه محیط توسعه با اینترنت مرورگر بازدیدکننده سایت یکسان نیست.

## بازسازی تصویر BHA3000 — اصلاح بعدی کاربر

به درخواست کاربر برای کیفیت مشابه BHA5000 با پنل جلوی مشکی، `bha3000-enhanced.png` با ابزار تولید/ویرایش تصویر و ارجاع هم‌زمان به عکس اصلی BHA3000 و عکس واضح BHA5000 بازسازی شد. این تصویر بازسازی گرافیکی است، نه عکس رسمی جدید سازنده؛ مشخصات و PDF دستگاه تغییر نکرده‌اند. فایل اصلی برای منشأ محفوظ است. تصویر جدید در renderer مشترک همه نمایش‌های دستگاه استفاده می‌شود و دیگر برش کم‌وضوح قدیمی روی آن اعمال نمی‌شود. عکس BHA5000 دست‌نخورده باقی است.

حذف تب و محتوای معرفی سانا در سورس و خروجی انتشار بررسی شد. امکان مشاهده مستقیم سایت عمومی در محیط به دلیل CONNECT 403 وجود نداشت؛ لینک با پارامتر نسخه برای درخواست تازه HTML ارائه می‌شود و وضعیت کش مرورگر یا انتشار GitHub از روی سورس حدس زده نمی‌شود.
