# تغییرات بازخورد ۲ نوامبر ۲۰۲۶

۱۴ یادداشت فایل بازخورد کاربر، به همراه درخواست favicon:

| مورد                    | نتیجه                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| اسلایدر خودکار هوم      | پنج دستگاه، کنترل دستی، توقف، توقف هنگام تمرکز/hover و رعایت reduced motion                                  |
| ورود و منوی کاربر       | «ورود» با آیکون؛ نمایش نام مسئول و منوی سفارش‌ها، اطلاعات حساب، آدرس‌ها و خروج                               |
| تفکیک CBC / POCT        | گروه‌های جدا با لوگو و رنگ Getein و Wondfo؛ تکرار لوگو در کارت و صفحه مشخصات                                 |
| نام مرکز و تصویر        | آزمایشگاه بقراط؛ نشان تصویری SVG اختصاصی مرکز با تصویر آزمایشگاهی غیرشخصی                                    |
| حذف نوار بالای پنل      | حذف شد                                                                                                       |
| حذف بنر فهرست مصرفی‌ها  | حذف شد؛ منبع و وضعیت تأیید محصول در جزئیات بسته باقی است                                                     |
| عکس کیت‌ها              | کاست و ID chip واقعی از PDF همان خانواده؛ تصویر مرجع است و عکس اختصاصی SKU ادعا نمی‌شود                      |
| منوی جمع‌شونده          | وضعیت ذخیره‌شونده دسکتاپ و باز/بسته شدن موبایل؛ نام لینک‌ها برای دسترس‌پذیری حفظ شده                         |
| شمارنده و موجودی        | +/− پس از افزودن، حد موجودی و جلوگیری از تعداد منفی؛ موجودی خواناتر و حذف پسوندهای تکراری                    |
| حذف لینک ادمین از مشتری | حذف کامل دکمه تغییر به مدیریت از پنل مشتری؛ ورود مدیر فقط از صفحه ورود                                       |
| journey و تراز سفارش    | سه مرحله برای سفارش جاری، سوابق/کنسل/رد بدون journey؛ ستون‌های هم‌تراز و دکمه رنگی خواناتر                   |
| سابقه تیکت              | یک پرسش و پاسخ اولیه درباره راه‌اندازی و کنترل کیفیت                                                         |
| حذف متن ثابت پروفایل    | حذف شد؛ اطلاعات ویرایش‌پذیر جایگزین آن شد                                                                    |
| مرکز و آدرس‌ها          | ویرایش مرکز؛ چند آدرس با پیش‌فرض، استان/شهر، موقعیت نقشه و انتخاب در checkout؛ snapshot مستقل از ویرایش بعدی |
| favicon با S            | SVG مستقل و self-contained با شکل S فایل اصلی؛ رنگ قرمز سانا؛ مسیر درست برای زیرمسیر Pages                   |

داده مرورگر فعلی بدون reset مهاجرت می‌کند. اگر نام مرکز یا اطلاعات مسئول قبلاً شخصی‌سازی شده باشند، متن سفارشی حفظ می‌شود و به نام نمونه تحمیل نمی‌شود. سفارش‌ها و قیمت‌های گذشته تغییر نمی‌کنند. یادداشت‌های بازخورد با کلید جدا باقی می‌مانند.

محدودیت‌های عمدی: نقشه آفلاین فاقد خیابان و geocoding است؛ مرکز شهرها تقریبی است. عکس اختصاصی همه کیت‌ها در منابع موجود نبود و عکس مرجع Finecare استفاده شده است. پرداخت/احراز هویت/پیامک و رویدادهای بیرونی با حذف متن‌های اضافی از رابط، واقعی نشده‌اند؛ مرزهای دمو در README و PRODUCTION.md مستندند.
