# گزارش بررسی دمو

تاریخ: ۲۰۲۶-۱۱-۰۱. محیط آزموده‌شده: Node 24.19.0، npm 11.9.0 و Chromium موجود سیستم.

| بررسی                                                                   | نتیجه                                   |
| ----------------------------------------------------------------------- | --------------------------------------- |
| نصب دوباره با `npm ci --cache /tmp/sana-npm-cache --no-audit --no-fund` | موفق، بدون تغییر lockfile               |
| `npm run typecheck`                                                     | موفق                                    |
| `npm test`                                                              | ۱۱ تست اجراشده، ۱۱ موفق، بدون skip      |
| `npm run build`                                                         | موفق؛ TypeScript و خروجی Vite           |
| `npm run test:e2e`                                                      | ۵ تست مرورگر اجراشده، ۵ موفق، بدون skip |
| اجرای توسعه و درخواست محلی HTTP                                         | موفق                                    |
| مخزن قبلی                                                               | بدون تغییر فایل                         |

آزمون‌های منطق شامل تخفیف بدون گردکردن دلخواه، idempotency ثبت و پرداخت، شکست پرداخت، تأیید/رد شرایطی، موجودی و سازگاری نمایشی، snapshot سفارش، سفارش مجدد، برآورد سابقه کافی/ناکافی، تلاش مجدد adapter، تاریخ شمسی و لغو سفارش pending هستند.

تست‌های مرورگر سفر کامل مشتری و مدیریت را اجرا می‌کنند: انتخاب مصرفی از دستگاه، جست‌وجوی کد، پرداخت ناموفق و موفق روی همان سفارش، تأیید/رد شرایطی با توضیح، ارسال و مشاهده در مشتری، تغییر قیمت و سفارش مجدد، تیکت و پاسخ، یادآور بدون رویداد تکراری، تلاش ناموفق/موفق SERVICELOGS بدون سفارش تازه، refresh و reset، OTP/رمز/بازیابی و خروج، ایجاد/غیرفعال‌سازی مرکز، تخصیص دستگاه و تحویل اولیه با تاریخ شمسی، تغییر موجودی و غیرفعال شدن سفارش قلم ناموجود.

همچنین ۲۳ مسیر عمومی و پنل در دو عرض ۳۹۰ و ۱۴۴۰ پیکسل بررسی شدند: RTL، نبود اسکرول افقی کل صفحه و نبود خطای JavaScript. منوی افقی داخل پنل موبایل عمداً قابل پیمایش است. هر پنج PDF با امضای `%PDF` و فونت/لوگوی محلی با پاسخ موفق بررسی شدند. در سفر اصلی، هیچ درخواست خارج از origin برنامه مشاهده نشد.

تصاویر خانه و پنل در دسکتاپ و موبایل به‌صورت دیداری بررسی شدند. فضای اضافی تصاویر BHA3000/BHA5000 با viewport مستند اصلاح شد؛ لوگو تک‌رنگ قرمز با شکل اصلی، فونت محلی، جهت مدل/کد و خوانایی فرم‌ها بررسی شد. عکس واقعی بسته کیت در منابع موجود نبود؛ تصویر نمادین صریحاً برچسب دارد.

مواردی که آزموده یا ادعا نشده‌اند: پرداخت/پیامک/CRM واقعی، احراز هویت امن، داده چندکاربره سمت سرور، موجودی واقعی سانا، IFU و SKU قابل عرضه، اندازه بسته، سازگاری علمی قطعی، قیمت بازار ایران، انتشار عمومی و بازیابی snapshot در یک task تازه. جزئیات منابع و کمبودها در CONTENT-SOURCES.md است.

نصب در محیط جاری تکرار شد و install_script و start_skill ذخیره شدند. ذخیره پیش‌نویس تنظیمات با انتشار یا اعتبارسنجی ماشین تازه یکسان نیست؛ انتشار فقط با اقدام کاربر در تنظیمات محیط انجام می‌شود.

## بررسی انتشار GitHub Pages

پس از درخواست انتشار روی Pages، مسیر دارایی‌ها برای `/SanaWebsite/` اصلاح شد. `npm run test:pages` روی خروجی production همان زیرمسیر موفق بود: عکس، فونت، PDF، سفارش/پرداخت مشتری، ماندگاری پس از refresh و عرض موبایل، بدون درخواست HTTP ناموفق یا خطای JavaScript. ۱۱ تست منطق و ۵ تست مرورگر توسعه نیز دوباره موفق شدند. ارسال خروجی به `gh-pages` با فعال بودن Pages و تأیید نشانی عمومی یکسان نیست؛ وضعیت فعال‌سازی در تنظیمات GitHub کنترل می‌شود.

## حالت بازخورد روی صفحه

پس از افزودن بازخورد، build و TypeScript موفق بودند و ۸ تست مرورگر (۵ سفر قبلی + ۳ سفر بازخورد) موفق اجرا شدند. تست‌های جدید انتخاب دکمه بدون اجرای آن، ثبت/ویرایش/انجام‌شده/حذف یادداشت، ماندگاری پس از refresh، حفظ صفحه و اندازه نمایشگر در فایل دانلود، تغییر نقش، لغو انتخاب با Escape، مستقل بودن از reset دمو و برداشت نکردن مقدار رمز را بررسی می‌کنند. رابط ثبت یادداشت در عرض موبایل و دسکتاپ به‌صورت دیداری بررسی شد؛ عرض صفحه در حالت پنل باز هم از نمایشگر تجاوز نمی‌کند. متن یادداشت، قبل از خروجی، فقط در مرورگر کاربر است و هیچ شبکه یا سرویس دریافت بازخورد اضافه نشده است.

## بازخوردهای ۱۴گانه و favicon — ۲۰۲۶-۱۱-۰۲

- ۱۴ تست منطق با موفقیت اجرا شدند؛ علاوه بر قواعد قبلی، مهاجرت غیرمخرب داده، حفظ سفارشی‌سازی، اعتبارسنجی پروفایل، انتخاب نشانی و snapshot مستقل آن، تغییر پیش‌فرض و حذف آدرس و نگاشت مراحل سفارش بررسی شدند.
- ۱۲ تست مرورگر موفق بودند؛ چهار سفر تازه، حرکت خودکار و توقف اسلایدر، گروه‌های سازنده، منوی حساب، نبود لینک مدیریت در مشتری، منوی جمع‌شونده و ماندگاری آن، تصویر کیت و شمارنده موجودی، ویرایش پروفایل، انتخاب استان/شهر و نقطه نقشه، ذخیره و انتخاب آدرس در checkout، حفظ موقعیت و متن نشانی پس از ویرایش آدرس، سوابق بدون journey و مهاجرت داده موجود را بررسی می‌کنند. تغییر نشانی ادمین و نمایش همان نشانی در مشتری هم بررسی شد. سفرهای قدیمی صرفاً با نام‌های جدید دکمه‌ها و تیکت اولیه تطبیق داده شدند؛ بررسی‌های تجاری باقی ماندند.
- `npm run test:pages` موفق بود: TypeScript و build مخصوص `/SanaWebsite/`، تصویر، فونت، PDF، مسیر و پاسخ favicon SVG، خرید و پرداخت و refresh و ذخیره بازخورد روی خروجی production. هیچ HTTP ناموفق یا خطای JavaScript در سفر تولید مشاهده نشد.
- favicon مستقیماً در مرورگر رندر و به‌صورت دیداری بررسی شد: تنها حرف S، قرمز و بدون حروف مجاور. لوگوی اصلی دست‌نخورده است.
- خانه و گروه‌بندی دستگاه‌ها، کارت کیت در موبایل، جدول سوابق روی دسکتاپ و فرم باز ویرایش آدرس/نقشه در موبایل دیداری بررسی شدند. عرض محتوای فرم باز روی نمایشگر ۳۹۰ پیکسل دقیقاً ۳۹۰ بود؛ اسکرول افقی کل صفحه ایجاد نشد.

حدود این بررسی: نقشه آفلاین و عکس‌های مرجع خانواده، عکس/نقشه اختصاصی همه SKUها و خیابان‌ها نیستند. پرداخت و سرویس‌ها همچنان محلی و شبیه‌سازی‌شده‌اند. آزمون تولید محلی و ارسال شاخه انتشار، تأیید پاسخ عمومی github.io از این شبکه محسوب نمی‌شود.

## تقویم تحویل، OpenStreetMap و تصاویر متمایز — ۲۰۲۶-۱۱-۰۲

- `npm test`: ۱۹ تست اجرا شد و همگی موفق بودند. بررسی‌های تازه شامل مرز نیمه‌شب تهران (۲۰:۳۰ UTC در تاریخ آزمون)، دو روز تقویمی آینده، عبور سال Gregorian، اسفند کبیسه و نوروز، رد تاریخ امروز/فردا/نامعتبر، محدود بودن به سه بازه، snapshot موعد و idempotency، یک‌بار افزوده شدن سفارش نمونه و تبدیل وضعیت قدیمی به کنسل است.
- `npm run test:e2e`: ۱۷ تست مرورگر موفق بودند. امروز و فردای تهران در تقویم غیرفعال‌اند، تغییر تاریخ و بازه در سفارش و refresh باقی می‌ماند، حداقل روز بدون reload در عبور نیمه‌شب عوض می‌شود، SANA-1004 در حال بررسی دیده می‌شود و گزینه وضعیت «رد شده» وجود ندارد. تفاوت SVG تصاویر CRP/TSH، برش مشترک Getein و favicon بدون فیلتر/bitmap/پس‌زمینه بررسی شده‌اند.
- تست نقشه از پاسخ تصویری کنترل‌شده برای درخواست کاشی استفاده می‌کند: URL استاندارد OpenStreetMap، attribution، تمرکز روی شیراز، کشیدن واقعی نشان با mouse، تغییر مختصات، خطای شبکه و تلاش مجدد موفق با حفظ مختصات آزموده شدند. موفقیت این تست‌ها، دسترسی واقعی این محیط به tile.openstreetmap.org را ثابت نمی‌کند؛ سیاست جاری محیط هنوز آن دامنه را مجاز نکرده است.
- `npm run test:pages`: TypeScript و build و سفر تولید زیر `/SanaWebsite/` موفق بودند؛ favicon با query نسخه و مسیر پروژه درست سرو شد. نقشه و CSS آن در chunk جدا فقط هنگام ویرایش آدرس بارگیری می‌شوند؛ هشدار chunk اولیه بزرگ‌تر از ۵۰۰ کیلوبایت برطرف شد، بدون بالا بردن حد هشدار.
- روی نمایشگر ۳۹۰ پیکسل، فرم کامل checkout و تقویم/بازه‌ها دیداری بررسی شد؛ عرض سند ۳۹۰ بود. برش Getein و favicon ۶۴×۶۴ هم در مرورگر رندر شدند؛ آلفای گوشه favicon صفر است و فقط S تخت قرمز دیده می‌شود. کارت‌های گرافیکی با نام/کد و رنگ‌های متفاوت بررسی شدند.

در محیط توسعه، پیش‌نویس مجازکردن `tile.openstreetmap.org` ذخیره شده است؛ اعمال آن به ذخیره و انتشار تنظیمات محیط نیاز دارد. اینترنت مرورگر کاربر سایت Pages مستقل از این سیاست است. اتصال‌های تجاری همچنان شبیه‌سازی‌شده‌اند و زمان تحویل در نسخه عملیاتی به ساعت/اعتبارسنجی سرور و سیاست ظرفیت نیاز دارد.

## بازخورد دوم — خوانایی، سبد و داشبورد

- `npm test`: ۱۹ آزمون منطق موفق؛ `npm run test:e2e`: هر ۲۰ آزمون مرورگر موفق، شامل سه آزمون جدید برای انتخاب از پیشنهادها، شمارنده، حذف آخرین بسته، محاسبه قیمت هر دو روش و فیلتر ترکیبی.
- `npm run typecheck` و `npm run test:pages` موفق؛ خروجی واقعی `/SanaWebsite/`، منابع محلی، ثبت سفارش/پرداخت، بازخوانی و RTL موبایل بدون خطای HTTP یا JavaScript بررسی شد.
- تصاویر واقعی مرورگر برای داشبورد دسکتاپ و سبد پُر موبایل ۳۶۰ پیکسلی بررسی شدند. قیمت واحد و جمع ردیف در موبایل هم‌زمان قابل مشاهده‌اند؛ عرض هر سلول قیمت ۱۴۲ پیکسل و scrollWidth همان ۱۴۲ بود، بدون بریدگی.
- فایل بازخورد اصلی در داده ذخیره‌شده کاربران دست‌کاری نمی‌شود؛ این تغییرات طراحی، یادداشت‌های شخصی و سفارش‌های موجود را پاک نمی‌کنند.
- مبنای گروه‌بندی کاتالوگ تصویری صفحه ۱ Finecare FS-114 است؛ رندر محلی آن بررسی شد. شرح ردیابی تمام یادداشت‌ها و تفاوت عناوین ناوبری در `docs/FEEDBACK-2026-11-02-SECOND.md` است.
